## 2024-05-24 - Array Map Consolidation
**Learning:** Chaining `.map()` passes on large arrays (like parsing raw relationships in `src/graph.ts`) doubles iteration overhead and triggers unnecessary intermediate object allocations, but completely unwinding them into raw `for` loops can violate the codebase's readability constraints (micro-optimization).
**Action:** Consolidate sequential `.map()` or `.filter()` passes into a single pass using functional `.reduce()` or a single `.map()` that builds auxiliary arrays as a side-effect, preserving readability while halving iteration overhead and O(N) intermediate allocations.
