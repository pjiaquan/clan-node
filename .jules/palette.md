## 2025-01-08 - Modal autoFocus pattern
**Learning:** Adding the `autoFocus` property to the first input field of modals is an extremely effective micro-UX improvement. It saves users a click and allows them to start typing immediately, which also aligns with WAI-ARIA best practices for dialog accessibility (focus should move into the dialog when it opens).
**Action:** When implementing or refining modals, consistently identify the primary input or interactive element and apply `autoFocus` to enhance keyboard accessibility and reduce friction.
